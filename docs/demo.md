# Demo script — Serverless OrderFlow

Use this 2–3 minute flow when presenting the repository to a client.

## 1. Start with the problem

An event-driven serverless order workflow demonstrating asynchronous processing, least-privilege infrastructure, Infrastructure as Code, structured logging and scalable cloud architecture.

## 2. Show the architecture

Open [`architecture.md`](architecture.md) and explain the request/data flow.

## 3. Show the happy path

Run the local project, open the UI/API docs, perform one realistic operation, then show the resulting state.

## 4. Show engineering quality

Open the test suite, CI workflow, CodeQL workflow and Dependabot configuration.

## 5. Close with production scaling

Explain authentication/authorization, managed databases, secrets, observability, deployment and backups as the next production layer.
