# Security

- Never commit `.env`, API keys, cloud credentials, private keys or production data.
- Use `.env.example` as a template only.
- Enable GitHub Dependabot, secret scanning/push protection and code scanning for public repositories.
- For production deployments, use a managed identity provider, secret manager and least-privilege IAM.

## Reporting
Please open a private security report through GitHub Security Advisories rather than publishing exploitable details in a public issue.
